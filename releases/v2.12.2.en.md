# Prompt Optimizer v2.12.2

## Summary
- Fixed the desktop AI configuration modal issuing an unauthenticated model-list request that the gateway rejected with 401 "Invalid token".
- Opening the modal now loads the saved provider configuration before fetching model options, and skips the models request entirely when neither a base URL nor an API key is configured.
- The main-process `ai-config-fetchModels` handler now falls back to the loaded `ai.yml` values when the incoming form config lacks connection fields.

## Highlights
- Desktop users no longer see a spurious 401 error when opening the AI configuration modal before any provider settings have been saved.

## Product Updates
### Desktop
- Serialized configuration loading before model option fetching in `AiConfigModal`, eliminating the parallel race that sent an Authorization-less models request on modal open.
- The models request is skipped when both `base_url` and `api_key` are empty, and the IPC handler falls back to the loaded `ai.yml` values.
### Web
- No web-specific user-facing changes in this release.
### Extension
- No extension-specific user-facing changes in this release beyond version metadata sync to `2.12.2`.
### Core/Infra
- No core/infra changes beyond version metadata sync and release artifacts.

## Fixes
- Fixed a 401 "Invalid token" error when the desktop AI config modal fetched model options before the saved configuration had loaded.

## Breaking Changes / Upgrade Notes
- No breaking changes. The desktop fix is backward compatible with existing `ai.yml` configurations.

## Developer Notes
- The code range for this fix set is `v2.12.0..HEAD`.
- v2.12.1 was never published as a GitHub release; this release ships the same patch content under the v2.12.2 tag.
- Version sync updates the root package, desktop package, and extension manifest to `2.12.2`.
