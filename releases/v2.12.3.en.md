# Prompt Optimizer v2.12.3

## Summary
- Fixed Windows auto-launch opening a blank Electron window instead of Prompt Optimizer when a development login item had been left behind.
- Development builds no longer write system auto-launch entries, while packaged builds explicitly register the current `PromptOptimizer.exe` with the configured silent-start argument.
- Packaged Windows builds now safely remove only the exact legacy `electron.app.Electron` entry that points to this repository's `electron.exe --hidden` command.

## Highlights
- Windows startup now launches the installed Prompt Optimizer application rather than a bare Electron runtime.

## Product Updates
### Desktop
- Restricted system auto-launch registration to packaged builds so local development sessions cannot create persistent OS login items.
- Explicitly binds the Windows login item to the running packaged executable and recalibrates it on every successful application startup.
- Added a guarded migration for the legacy development Run value, with strict value-name, executable-path, repository-path, and argument matching before deletion.
### Web
- No web-specific user-facing changes in this release.
### Extension
- No extension-specific user-facing changes in this release beyond version metadata sync to `2.12.3`.
### Core/Infra
- Added focused desktop regression coverage for packaged and unpackaged startup settings, macOS compatibility, registry parsing, and guarded cleanup behavior.

## Fixes
- Fixed Windows login starting a bare `electron.exe --hidden` process that displayed an Electron blank window.
- Fixed packaged login-item registration relying on an implicit executable path and only synchronizing during first-run initialization.

## Breaking Changes / Upgrade Notes
- No breaking changes. Existing auto-launch and silent-start preferences are preserved.
- The first successful startup of this release removes the legacy development login item only when it exactly matches the known Prompt Optimizer development command.

## Developer Notes
- The code range for this release is `v2.12.2..v2.12.3`.
- Auto-launch policy and migration parsing live in `packages/desktop/config/login-item-settings.js` with Node test coverage.
- Version sync updates the root package, desktop package, and extension manifest to `2.12.3`.
