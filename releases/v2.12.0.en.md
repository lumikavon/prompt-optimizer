# Prompt Optimizer v2.12.0

## Summary
- Major UI refactor: removed the legacy context (Pro) mode, the favorites library workspace, and the multi-column test deck from Basic and Image workspaces. The application now focuses on Basic mode (system/user prompt optimization) and Image mode (text-to-image, image-to-image, multi-image), each following the input → analyze/optimize → evaluate flow.
- Image mode keeps local reference-image inputs (single or multi) for composing prompts.
- Reworked the desktop experience with an in-app AI configuration manager, custom window controls, and packaged app icons.
- Made the whole UI responsive: fluid split-pane grids with proportional minimum bounds, wrapping navigation and headers, fluid dialogs and selects, and viewport-safe content padding.

## Highlights
- A single cleaner workspace model: choose between Basic and Image modes and keep prompt templates, variable-aware inputs, and the analysis/evaluation pipeline.
- Desktop users can now manage their AI provider configuration directly inside the app instead of editing config files by hand.

## Product Updates
### Desktop
- Added an in-app AI configuration manager (`AiConfigModal`) backed by a dedicated `ai-config.js` module, so provider/API configuration is editable from the UI.
- Added custom `WindowControls` (minimize/maximize/close) and packaged application icons.
- Unsigned macOS builds now route their update metadata to GitHub Releases, keeping auto-update channels working without a signing certificate.
### Web
- The web app inherits the same focused workspace model (Basic + Image modes) after the legacy context/favorites removal, and the responsive layout works across the full viewport range.
### Extension
- No extension-specific user-facing changes shipped in this release beyond version metadata sync to `2.12.0`.
### Core/Infra
- Core prompt, evaluation, and OpenAI adapter layers now handle multimodal (image + text) requests, with Electron IPC serialization updated to carry image data safely.
- Removed legacy favorites/context-mode services, tests, and VCR fixtures alongside the UI removal.

## Fixes
- Fixed invalid CSS `border` value and a broken `class` attribute in the cleanup pass.
- Fixed a passive scroll-listener warning in the responsive layout.
- Corrected an SSRF issue reference in the documentation.

## Breaking Changes / Upgrade Notes
- The context (Pro) mode, the favorites library, and the multi-column test/generation deck in Basic and Image workspaces are removed. Data stored under those legacy features is no longer displayed; keep an exported backup if you still need it.
- Prompt templates, Prompt Garden import, and image-mode variables are unaffected and remain the recommended way to reuse prompts.

## Developer Notes
- The release range is `v2.11.7..HEAD`.
- Version sync updates the root package, desktop package, and extension manifest to `2.12.0`.
- Verification covered `pnpm test:gate`, `node scripts/release-notes.js check v2.12.0`, and `git diff --check`.
