# Prompt Optimizer v2.12.0

## 概括
- 大规模 UI 重构：移除了旧的上下文（Pro）模式、收藏库工作区，以及基础/图像工作区中的多列测试区。应用现在聚焦基础模式（系统/用户提示词优化）与图像模式（文生图、图生图、多图），每个工作区遵循「输入 → 分析/优化 → 评估」的流程。
- 图像模式保留本地参考图输入（单图或多图），用于组合提示词。
- 重构桌面端体验：新增应用内 AI 配置管理、自定义窗口控制与打包图标。
- 全 UI 响应式适配：流体分栏网格与比例最小边界、可换行的导航与页头、流体对话框与下拉框，以及视口安全的页面留白。

## 亮点
- 更简洁统一的工作区模型：在基础模式与图像模式之间选择，并保留提示词模板、变量感知输入以及分析/评估链路。
- 桌面端用户现在可以直接在应用内管理 AI 供应商配置，无需再手工编辑配置文件。

## 产品更新
### Desktop
- 新增应用内 AI 配置管理（`AiConfigModal`），基于独立的 `ai-config.js` 模块，可在界面中直接编辑供应商/API 配置。
- 新增自定义 `WindowControls`（最小化/最大化/关闭）与打包应用图标。
- 未签名的 macOS 构建现在将更新元数据发布到 GitHub Releases，无需签名证书即可维持自动更新通道。
### Web
- 移除旧上下文/收藏功能后，Web 应用同样采用聚焦的工作区模型（基础 + 图像模式），响应式布局覆盖完整视口范围。
### Extension
- 本次发布没有扩展端独有的用户可见变化，只有版本元数据同步到 `2.12.0`。
### Core/Infra
- 核心提示词、评估与 OpenAI 适配层现已支持多模态（图片 + 文本）请求，Electron IPC 序列化同步更新以安全携带图片数据。
- 随 UI 移除一并清理了旧的收藏/上下文模式服务、测试与 VCR 夹具。

## 修复
- 修复清理过程中无效的 CSS `border` 值与损坏的 `class` 属性。
- 修复响应式布局中的被动滚动监听警告。
- 修正文档中对 SSRF 问题的引用。

## 破坏性变更 / 升级说明
- 上下文（Pro）模式、收藏库以及基础/图像工作区中的多列测试/生成区已移除。旧功能下保存的数据不再展示；如仍需使用，请保留导出的备份。
- 提示词模板、Prompt Garden 导入与图像模式变量不受影响，仍是复用提示词的推荐方式。
