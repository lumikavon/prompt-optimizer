# Prompt Optimizer v2.12.3

## 概括
- 修复 Windows 开机自启动遗留开发登录项时，打开 Electron 空白窗口而非 Prompt Optimizer 的问题。
- 开发构建不再写入系统开机自启动项；正式包会明确注册当前 `PromptOptimizer.exe`，并保留已配置的静默启动参数。
- Windows 正式包现在只会安全清理精确指向本仓库 `electron.exe --hidden` 命令的旧 `electron.app.Electron` 登录项。

## 亮点
- Windows 系统启动后将打开已安装的 Prompt Optimizer，不再启动裸 Electron 运行时。

## 产品更新
### Desktop
- 系统开机自启动注册仅允许正式打包版本执行，避免本地开发会话创建持久化操作系统登录项。
- Windows 登录项明确绑定当前运行的正式包可执行文件，并在每次应用成功启动时重新校准。
- 新增受保护的旧开发 Run 值迁移逻辑，删除前严格校验值名、可执行文件路径、仓库路径和启动参数。
### Web
- 本次发布没有 Web 端独有的用户可见变化。
### Extension
- 本次发布没有扩展端独有的用户可见变化，只有版本元数据同步到 `2.12.3`。
### Core/Infra
- 新增桌面端回归测试，覆盖正式包与开发包启动设置、macOS 兼容行为、注册表解析及受保护清理。

## 修复
- 修复 Windows 登录时启动裸 `electron.exe --hidden` 进程并显示 Electron 空白窗口的问题。
- 修复正式包登录项依赖隐式可执行文件路径、且仅在首次运行时同步的问题。

## 破坏性变更 / 升级说明
- 没有破坏性变更，现有开机自启动和静默启动偏好会继续保留。
- 本版本首次成功启动时，仅在旧开发登录项与已知 Prompt Optimizer 开发命令完全匹配时执行清理。

## 开发者说明
- 本次发布的代码范围是 `v2.12.2..v2.12.3`。
- 开机自启动策略与迁移解析位于 `packages/desktop/config/login-item-settings.js`，并配有 Node 测试。
- 版本同步会把根包、桌面包和扩展 manifest 一起更新到 `2.12.3`。
